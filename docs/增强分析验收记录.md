- 原模拟基线：B0/B1传球树重新拟合旧版规则；带球保有率1；射门原公式。
- 主模型：独立几何战术概率＋两步动作展望＋xT尾值。没有训练FQI或真实足球策略。

- 模型、规则文件哈希随评分索引记录；预测点、候选持续时间与结果均明确属于模型假设。
